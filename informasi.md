<!-- Tutorial Bikin Branch -->
1. git checkout -b nama-branch-baru
2. git branch nama-branch-baru
3. git commit -m ""
4. git push -u origin nama-branch-baru

<!-- Important -->
1. Gunakan AI hanya untuk mempercepat pekerjaan.
2. Baca doa sebelum Mulai Projek.
3. Kerja sama dan komunikasi ketika ingin menambahkan fitur atau sesuatu.
4. Push ke Branch masing-masing terlebih dahulu.

<!-- Command Di commit -->
Ketika ingin melakukan commit sebisa mungkin gunakan beberapa penanda, agar mudah untuk saat merge
contoh :
        commit -m "fix: bug-navbar".

ini beberapa command yang lain : - refactor: Mengubah kode tanpa menambah fitur atau memperbaiki bug
                                 - feat: Menambahkan fitur baru (contoh: feat: add login endpoint).
                                 - fix: Memperbaiki bug (contoh: fix: resolve null pointer in payment gateway).
                                 - chore: Pemeliharaan rutin (contoh: pembaruan dependency)
